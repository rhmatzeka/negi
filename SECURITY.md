# Security

negi gives a paired phone the Mac's terminals and screen, so a flaw in it matters.

Please report a vulnerability privately through GitHub's
[security advisories](https://github.com/rifuki/negi/security/advisories/new), not in a
public issue. Say what is affected, how to reproduce it, and which version. You will get an
answer within a few days.

What is in scope: anything that lets someone other than the paired owner read or drive the
Mac through negi, or that weakens pairing, the sealed screen login, or the Mac password
check before live video.
